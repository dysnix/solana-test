# Yellowstone gRPC benchmark

This benchmark will make request to 2 endpoints, subscribe to transactions stream and compare which of them is faster. 
Network latency between test station and GRPC endpoint does not affect results, as timestamps of transactions are generated by GRPC plugin on server side.

## Run benchmark

1. Select appropriate binary for your OS and CPU arch.

2. Please run benchmark like in a following example. It will collect transactions for 5 minutes and then print the results.

```bash
./bin/bench_linux_arm64 \
    -url1 first-yellowstone-endpoint:port \
    -token1 abcdef1234 \
    -url2 second-yellowstone-endpoint:port \
    -token2 4321fedcba \
    -duration 5m \
    -file first.txt \
    -file second.txt
```
